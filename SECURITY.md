# Security policy

This policy covers every repository in the itinera-dev organisation that has no security policy of its own.

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub:

1. Open the affected repository on GitHub.
2. Go to its Security tab.
3. Select "Report a vulnerability" and describe the problem, how to reproduce it, and what it affects.

Do not report a vulnerability in a public issue, pull request or discussion.

The report is visible only to the maintainers. We will acknowledge it, keep you informed while we work on it, and credit you in the advisory when it is published, unless you prefer not to be named.

## Supported versions

Until version 1.0, only the latest release of each package receives security fixes.
